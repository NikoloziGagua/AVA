# AVA frontier interface lab

This is a standalone, offline-openable design prototype. It does not modify AVA's
live interface or depend on a development server.

## Open it

Double-click `index.html`, or open it in any current browser. The three concepts
are selectable from the header or with the number keys:

1. **Presence** — AVA as a calm, living assistant rather than a dashboard.
2. **Constellation** — a spatial life overview that connects schedule, people,
   notes and projects without turning them into a dense admin grid.
3. **Continuum** — conversation as the control surface, with structured results
   unfolding inline and persistent context remaining visible.

Press `M` to switch between full and reduced motion. The preview also honours
the operating system's `prefers-reduced-motion` setting. Everything is local:
there are no fonts, images, analytics, CDNs or network requests.

## What this is for

Use the lab to compare interaction principles, not to select a page template.
The recommended AVA direction combines the calm centre of Presence, the
progressive disclosure of Constellation, and the inline structured results of
Continuum. The accompanying research and adoption notes are in
`../../../research/frontier-ui-2026-09-25.md`.
