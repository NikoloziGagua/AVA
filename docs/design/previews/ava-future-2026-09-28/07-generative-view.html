What's demo

  • The "generation" is a pre-built view with an animation.
  • The option ratings (cost, time, signal…) are illustrative, not researched.

What would be real

  • The model picks a view type (compare, simulate, plan) and fills it with sourced data.
  • Every number links to where it came from.
  • The view saves to the conversation.

How it plugs into AVA

This extends AVA's existing Visual explanations: same sandbox, same "open the exact visual" links. It adds interactive controls in place of static diagrams.

Grounding

Google's generative UI research: people strongly preferred generated interfaces over plain text, rating them close to expert-designed pages. The caveats: they can take a minute or more, with occasional errors.
