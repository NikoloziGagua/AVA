What's demo

  • Every node and link is invented.
  • The 3D view is a lightweight custom canvas renderer made for this preview.

What would be real

  • Nodes are exact records: Notes, calendar events, confirmed goals, recorded decisions.
  • Links are explicit (cited, filed in, decided because of), never guessed similarity.

How it plugs into AVA

A visual layer over Decision Replay and Notes, not a new database. AVA already ships React Flow (MIT). For true 3D, 3d-force-graph is MIT-licensed.

Honest take

This is the "wow" layer. On its own it's graph ornament; it earns its place only on top of real decision links (Codex's review). Build it after Decision Replay, not before.
